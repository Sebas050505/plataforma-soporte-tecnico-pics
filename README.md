# Plataforma Inteligente para la Gestión de Soporte Técnico

**Proyecto Integrador de Computación y Sistemas (PICS) II-2026**  
Escuela Tecnológica Instituto Técnico Central (ETITC)

**Autor:** Sebastian Yamith Manrique Godoy  

**Asesores:**  
José Fernando Ruiz Quintana · Celio Gil Aros · Edwin Alberto Mendoza Mazo

## Descripción
Plataforma web inteligente que gestiona el ciclo completo de soporte técnico:  
reporte en lenguaje natural → triaje con IA → diagnóstico remoto → despacho zonal de técnicos → cierre formal con acta y firma digital → historial y KPIs.

## Contenido de este repositorio
- Documento formal del proyecto
- Presentación final
- Póster para exhibición
- Planes y evidencias de pruebas (Sprints 2 a 7)
- Diagrama entidad-relación y diccionario de datos
- Archivo de gestión del proyecto

## Stack tecnológico
n8n · MySQL · HTML/CSS/JavaScript · Token Auth · Scrum
